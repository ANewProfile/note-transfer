Almost there

This site needs a free Supabase project for storage. One-time setup:

  1. Create a project at supabase.com.
  2. Open SQL Editor, paste the contents of supabase/schema.sql from this repository, and click Run.
  3. Copy the Project URL and the anon / publishable key from Project Settings → API.
  4. Paste them into js/config.js, then commit and push.

See the README for details.

Secure connection required

Your browser only allows encryption on secure (https://) pages. Open this site over https, or on localhost for local testing.

Move notes between your devices.

Make a note space with a name and password, drop in snippets, tokens or text, then open it from any other device. Spaces delete themselves after at most 5 days.
